# 🛒 Flask E-Commerce Website

A simple E-Commerce website built using **Python, Flask, HTML, CSS, and SQLite**.

## 🚀 Features

- User Registration
- User Login
- Product Listing
- Product Search
- Category Filter
- Product Details
- Add to Cart
- Increase / Decrease Quantity
- Remove from Cart
- Checkout
- SQLite Database

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## 📂 Project Structure

```
Ecommerce/
│
├── app.py
├── database.db
├── requirements.txt
├── templates/
├── static/
└── README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run the project:

```
python app.py
```

5. Open your browser:

```
http://127.0.0.1:5000
```
